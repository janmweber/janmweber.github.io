Aufgabe E: Komplexe Fehleranalyse (Umfangreich)

Analysieren Sie den Code der Klasse DatenManager. Er enthält fünf verschiedene Kompilerfehler.

public class DatenManager { public static void main(String[] args) { double[] messwerte = {1.2, 3.5, 4.8}; int summe; for (int i = 0; i <= messwerte.length; i++) { summe = summe + messwerte[i]; } String info = "Ergebnis: " + summe; if (summe > 10) { boolean status = true; } System.out.println(info + " Status: " + status); checkLimit(summe); } public static void checkLimit(int s) { if (s > 100) return true; else return false; } }
Kompilerausgabe: 1. DatenManager.java:6: error: variable summe might not have been initialized
2. DatenManager.java:6: error: incompatible types: possible lossy conversion from double to int
3. DatenManager.java:14: error: cannot find symbol: variable status
4. DatenManager.java:19: error: incompatible types: unexpected return value (true)
5. DatenManager.java:20: error: incompatible types: unexpected return value (false)

Lösungsvorschlag

Zeile Fehlerursache Korrektur
6 Initialisierung: summe wird für eine Berechnung genutzt (summe + ...), hat aber noch keinen Startwert. int summe = 0; in Zeile 4.
6 Typkonflikt: Ein double aus dem Array kann nicht ohne Cast in ein int gespeichert werden[cite: 82]. summe = summe + (int)messwerte[i];
14 Scope: Die Variable status wurde innerhalb des if-Blocks deklariert und ist außerhalb nicht sichtbar. boolean status = false; vor dem if-Block deklarieren.
19/20 Rückgabetyp: Die Methode ist als void deklariert, versucht aber boolean-Werte zurückzugeben. Methodenkopf ändern: public static boolean checkLimit...
- Laufzeitfehler-Hinweis (Bonus): Zeile 5 würde einen ArrayIndexOutOfBoundsException auslösen, da i <= length auf einen Index zugreift, der nicht existiert. Ändern zu i < messwerte.length.
